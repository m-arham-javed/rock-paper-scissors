# Rock Paper Scissors Web Game

## Project Overview
An interactive browser-based **Rock Paper Scissors** game built with vanilla **JavaScript**, **HTML5**, and **CSS3**. Players compete against an automated computer opponent with randomized move generation, instant round outcome evaluation, and live score tracking.

## Key Features
* **Randomized Computer AI:** Generates unbiased computer choices (`Rock`, `Paper`, or `Scissors`) on every round.
* **Live Scoreboard & Round Feedback:** Dynamically updates player and computer scores alongside instant win, loss, or draw status messages via DOM manipulation.
* **Visual Move Selection:** Custom visual assets (`imgs/`) and hover/click states for intuitive gameplay.
* **Responsive Styling:** Clean layout and visual hierarchy powered by `game.css`.

## Project Structure
* **`game.html`:** Semantic HTML layout for the game arena, choice buttons, and scoreboard.
* **`game.css`:** Custom styling, button hover effects, and responsive layout rules.
* **`game.js`:** Core game loop, randomized computer choice logic, win/draw evaluation, and DOM updates.
* **`imgs/`:** Visual icons and graphic assets for Rock, Paper, and Scissors moves.

## Tech Stack
* **Languages:** JavaScript (ES6+), HTML5, CSS3
